## 📋 Project Overview

This website serves as an interactive educational resource about data privacy. It covers:

- What data privacy is and why it matters
- How companies misuse personal data
- Practical steps to protect yourself online
- Real-life (fictional cat-themed) privacy scenarios told through an image slideshow

---

## ✨ Features

- **Light/Dark Mode Toggle** — Switch between light and dark themes with a single button click
- **Interactive Info Table** — A dropdown-style section revealing privacy protection tips across five categories (cookies, viruses, privacy settings, network security, and identity theft)
- **Image Slideshow** — A narrative slideshow featuring fictional cat characters who experience real-world data privacy threats
- **Contact Form** — A Formspree-powered form for users to send messages or questions
- **Responsive Design** — Adapts layout and font sizes for mobile (≤480px) and desktop (≤2000px) screen sizes

## 🚀 Getting Started

No build tools or installations are required. Just open the project in a browser:

1. Clone or download the repository
2. Open `index.html` in any modern web browser

```bash
# Optional: serve locally with Python
python -m http.server 8000
# Then visit http://localhost:8000
```

## 📱 Responsive Breakpoints

| Screen Size | Behavior |
|-------------|----------|
| ≤ 480px (mobile) | Larger font (50px), dropdown hidden by default, toggle button shown |
| ≤ 2000px (desktop) | Standard font (18px), full layout shown |
